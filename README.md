# HydroTracker
HydroTracker is a smart hydration tracking web application that helps users monitor their daily water intake, set personalized hydration goals, and build healthy drinking habits through real-time progress tracking, achievements, email reminders, and smartwatch integration.

# Objectives
- Enable users to log water intake quickly and accurately
- Provide personalized daily hydration goals based on body weight and activity level
- Visualize progress through dashboards, charts, and historical analytics
- Encourage consistency through achievements, streaks, and rewards
- Send automated email reminders to keep users on track
- Extend accessibility to wearable devices (smartwatches)
